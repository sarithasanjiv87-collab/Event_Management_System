# Event Management System

## About the Project

The **Event Management System** is a web-based application designed to simplify event planning and management. It helps users manage events, bookings, and related information through a centralized platform.

## Features

- User Authentication
- Event Management
- Booking Management
- Database Integration
- User-friendly Interface
- Backend API Integration

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file using `.env.example` and configure your database credentials.

Start the backend:

```bash
npm start
```

Backend runs at:

`http://localhost:5000`

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at:

`http://localhost:5173`
